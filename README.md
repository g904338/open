# 長者用藥小卡

社區藥局用：輸入長者的 **姓氏、性別、年齡、腎功能（選填）、使用藥物**，產生一頁 A4、一眼看懂「什麼時間吃哪一顆」的用藥小卡。

判斷依據：
- **健保署藥品仿單**：用途、用法、注意事項、依腎功能調整劑量
- **2023 AGS Beers Criteria®**：65 歲以上的老人不適當用藥（表 2）、需謹慎使用（表 4）、藥物併用（表 5）、依腎功能避免或減量（表 6）

## 使用方式

不需安裝，用瀏覽器（Chrome / Edge）開啟 `index.html`。

1. **病人資料**：姓氏、性別、年齡，選擇小卡上的稱呼（先生／女士或阿公／阿嬤）。腎功能沒有資料就不用填。
2. **使用藥物**：搜尋或一次貼上多個藥名。每個藥依藥袋設定 **外觀（顏色、形狀）、顆數、服藥時間、用途**；時間和用途會先帶入常見設定，請務必依實際處方修改。
3. **列印內容**：系統依年齡、腎功能和用藥建議勾選下方提醒（預設最多 4 句提醒、3 條注意），句子可以直接修改。選擇列印語言後按「列印 / 存成 PDF」。
4. 「藥師提醒」分頁列出仿單與 Beers 的專業判斷，以及各藥的口頭衛教重點，**不會印出**。

### 用藥小卡版面（A4 一頁）

- **上方 2/3：用藥時間表**。依早餐前後、午餐前後、晚餐前後、睡前、需要時排列，每行「白色圓形 1 顆：降血壓」，旁邊小字標商品名方便對照藥袋。
- **下方 1/3：生活提醒與注意事項**。每個主題一句話（飲食、防跌、腎臟、回診…），紅字為需要馬上處理的狀況。
- 兩區各自調整字級，藥物區優先放大；字太小時右上角會提醒。

### 多語言

小卡的固定文字放在 `data/card.js` 的 `STR`，目前有中文與英文。新增語言時複製 `en` 一段翻譯即可，`tests/card.test.js` 會檢查是否缺字。**外文翻譯請由母語人士核對後再使用**；藥師在畫面上改過的句子會照原文印出。

### 白話原則

印出的文字不使用專業術語，`tests/plain-language.test.js` 會自動檢查，新增資料後請執行測試。

## 檔案結構

| 檔案 | 說明 |
|---|---|
| `index.html`、`css/style.css` | 介面與 A4 列印版面 |
| `js/app.js` | 介面互動、衛教單產生 |
| `js/renal.js` | 腎功能計算（CKD-EPI 2021、Cockcroft-Gault）與仿單規則判斷 |
| `js/beers.js` | Beers 2023 比對引擎 |
| `js/icons.js` | 小卡圖示（時段、主題、注意）與依顏色形狀繪製的藥丸圖 |
| `data/drugs.js` | 仿單資料（完整衛教內容，目前 14 個藥） |
| `data/beers2023.js` | Beers 2023 規則與藥名字典（約 140 個學名，含常見中文商品名） |
| `data/card.js` | 用藥小卡：時段、外觀、用途、提醒句子、多語言文字與勾選規則 |
| `tests/` | `node --test tests/*.test.js` |

## ⚠️ 上線前需核對

- `data/drugs.js`：請藥師對照 **健保署最新版仿單** 核對，填入健保代碼、許可證字號、仿單版本，並把 `verified` 改為 `true`。
- `data/beers2023.js`：內容依 Beers 2023 原文整理為中文，請對照原文核對；中文商品名請依藥局品項補充。
- Beers 表 3（藥物與疾病交互作用，例如失智、跌倒史、心衰竭）需要病人的診斷資料，尚未納入。
