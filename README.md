# 用藥衛教單

社區藥局用：輸入長者的 **姓氏、性別、年齡、腎功能（選填）、使用藥物**，自動產生一頁 A4、民眾看得懂的用藥衛教單。

判斷依據：
- **健保署藥品仿單**：用途、用法、注意事項、依腎功能調整劑量
- **2023 AGS Beers Criteria®**：65 歲以上的老人不適當用藥（表 2）、需謹慎使用（表 4）、藥物併用（表 5）、依腎功能避免或減量（表 6）

## 使用方式

不需安裝，用瀏覽器（Chrome / Edge）開啟 `index.html`。

1. **病人資料**：姓氏、性別、年齡。腎功能沒有資料就不用填；有的話填肌酸酐（加體重可算 CrCl），或直接填 eGFR／CrCl。
2. **使用藥物**：搜尋學名、商品名或中文名後按 Enter；多種藥可展開「一次貼上多個藥名」整批加入。
3. **衛教項目**：系統依年齡、腎功能和用藥「建議」勾選生活小叮嚀（用藥習慣、飲食、運動、睡眠、自我照顧），藥師確認後再印；也可自行輸入其他叮嚀。
4. 右側「衛教單預覽」即時更新，按「列印 / 存成 PDF」。「藥師提醒」分頁列出仿單與 Beers 的專業說明，**不會印出**。

### 一頁 A4

藥品多時會依序：縮小字級 → 改三欄 → 省略「可能的不舒服」 → 省略一般藥品的「要注意」。字小於 10px 會提醒藥師減少勾選項目；仍超過一頁時會警告。

### 白話原則

衛教單上的文字不使用專業術語（例如 eGFR、NSAID、抗凝血、禁用、劑量、透析）。`tests/plain-language.test.js` 會自動檢查所有會印出的文字，新增資料後請執行測試。

## 檔案結構

| 檔案 | 說明 |
|---|---|
| `index.html`、`css/style.css` | 介面與 A4 列印版面 |
| `js/app.js` | 介面互動、衛教單產生 |
| `js/renal.js` | 腎功能計算（CKD-EPI 2021、Cockcroft-Gault）與仿單規則判斷 |
| `js/beers.js` | Beers 2023 比對引擎 |
| `data/drugs.js` | 仿單資料（完整衛教內容，目前 14 個藥） |
| `data/beers2023.js` | Beers 2023 規則與藥名字典（約 140 個學名，含常見中文商品名） |
| `data/tips.js` | 生活小叮嚀項目與建議勾選條件 |
| `tests/` | `node --test tests/*.test.js` |

## ⚠️ 上線前需核對

- `data/drugs.js`：請藥師對照 **健保署最新版仿單** 核對，填入健保代碼、許可證字號、仿單版本，並把 `verified` 改為 `true`。
- `data/beers2023.js`：內容依 Beers 2023 原文整理為中文，請對照原文核對；中文商品名請依藥局品項補充。
- Beers 表 3（藥物與疾病交互作用，例如失智、跌倒史、心衰竭）需要病人的診斷資料，尚未納入。
