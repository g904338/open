# 個人化用藥衛教單產生器

輸入 **年齡、腎功能、使用藥物**，自動產生一頁 A4 的病人用藥衛教單。藥品資料以 **健保署藥品仿單** 為來源。

## 使用方式

不需安裝，直接用瀏覽器開啟 `index.html`。

1. 輸入年齡、性別、體重。
2. 腎功能：輸入血清肌酸酐（自動計算 eGFR〔CKD-EPI 2021〕與 CrCl〔Cockcroft-Gault〕），或直接輸入 eGFR / CrCl；可勾選「透析」。
3. 搜尋並加入藥物（學名、商品名、中文名皆可）。資料庫沒有的藥按 Enter 可自訂加入。
4. 右側即時預覽衛教單，按「列印 / 存成 PDF」輸出。內容過多時會自動縮小字級以維持一頁。

畫面上方的「藥師／醫師端提醒」會列出依仿單的劑量建議（不印在衛教單上）；衛教單本身只呈現病人看得懂的白話提醒。

## 檔案結構

| 檔案 | 說明 |
|---|---|
| `index.html` | 介面 |
| `js/renal.js` | 腎功能計算、分期、藥品規則判斷（純函式，可單元測試） |
| `js/app.js` | 介面互動與衛教單產生 |
| `data/drugs.js` | 藥品資料庫（仿單整理） |
| `css/style.css` | 樣式與 A4 列印版面 |
| `tests/` | 單元測試：`node --test tests/*.test.js` |

## ⚠️ 藥品資料需核對

`data/drugs.js` 目前收錄 14 個常用藥作為範例，內容依仿單常見記載整理，**尚未逐筆對照健保署最新版仿單**。上線前請藥師：

1. 對照健保署仿單核對每筆的劑量區間與衛教文字；
2. 填入 `nhiCode`（健保代碼）、`license`（許可證字號）、`insertVersion`（仿單版本）；
3. 將 `verified` 改為 `true`（未核對的藥在衛教單上會顯示「待核對」）。

新增藥品時複製一筆既有資料修改即可，欄位說明見 `data/drugs.js` 開頭註解。
